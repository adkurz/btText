# btText – Installation Guide

## Requirements

- Python 3.12 or higher
- A 64-bit Python installation is recommended

---

## Step-by-step Installation

### 1. Install Python

Download and install Python from [python.org](https://www.python.org/downloads/).  
During installation, check **"Add Python to PATH"**.

Verify the installation:

```bash
python --version
```

### 2. Create a virtual environment

Open a terminal in the project folder (`btText`) and run:

```bash
python -m venv .venv
```

Activate it:

- **Windows (Command Prompt):**
  ```cmd
  .venv\Scripts\activate.bat
  ```
- **Windows (PowerShell):**
  ```powershell
  .venv\Scripts\Activate.ps1
  ```

### 3. Install dependencies

For running the application from source:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

For development, translation work, tests, and packaging:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
```

### 4. Launch the application

Run the application with the virtual-environment interpreter:

```powershell
.\.venv\Scripts\python.exe btText.py
```

## Create a packaged Windows build

Run the build script from the project folder:

```powershell
.\build.ps1
```

The script creates `.venv` automatically when it is missing, installs all
build dependencies into it, and then uses only that environment for catalog
validation, tests, and PyInstaller. The globally available Python installation
is used only once to create `.venv`.

The finished portable archive is written to:

```text
build/btText-<version>-windows.zip
```

It contains the executable and immutable runtime resources. It does not contain
`data.db` or `settings.ini`; btText creates those files beside the executable
when they are needed.

To select the Python installation used to create `.venv`:

```powershell
.\build.ps1 -Python "C:\Path\To\python.exe"
```

## Data locations and first-run behaviour

When run from source or from the portable archive, btText stores
`settings.ini` and its default `data.db` beside the script or executable.

An installed build stores both files in the current user's roaming application
data directory:

```text
%APPDATA%\btText
```

If the active data directory does not already contain `data.db` and no database
is configured, btText asks whether to create a new database or open an existing
one. It does not search other folders, move a portable database, or delete the
original file automatically.

To continue using a database from a portable copy, choose **Open existing
database** on first start and select that copy's `data.db`. btText keeps the
database in its original location and stores its absolute path in the installed
settings.

Alternatively, before the first installed start, copy the portable `data.db`
to `%APPDATA%\btText\data.db`. btText then adopts it as the installed default
database and records it relatively as `data.db`.

## Uninstall

To remove the application:

1. Deactivate and delete the virtual environment:
   ```bash
   deactivate
   rmdir /s .venv          # Windows
   rm -rf .venv            # Linux/macOS
   ```
2. Remove installed packages (optional):
   ```bash
   pip uninstall wx pymitter
   ```
3. Delete the project folder, including `data.db`.
