# Änderungsprotokoll für btText

## [Unveröffentlicht]

- Der Name der aktiven Datenbank wird nun in der Titelleiste angezeigt.

- Hotstring-Erweiterung bei nicht verfügbaren Zwischenablageformaten behoben.

- Es wird nun zuverlässig verhindert, dass Hotstring-Erweiterungen und andere temporäre Einfügevorgänge im Verlauf der Windows-Zwischenablage gespeichert oder über die Cloud-Zwischenablage synchronisiert werden. Die Datenschutzeinstellungen der Zwischenablage gelten jetzt nur, wenn Snippets explizit über das Kontextmenü oder Strg+Umschalt+C kopiert werden.
